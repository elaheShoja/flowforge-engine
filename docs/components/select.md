# Select

The `Select` component is a flexible and reusable selection field designed for FlowForge forms and applications.

It supports single-value and multi-value selection, searchable options, option groups, disabled options, Select All behavior, validation states, and controlled usage.

---

## Overview

`Select` is one of the core field components of FlowForge.

It can be used independently or as part of a form generated by the FlowForge Form Builder.

### Key Features

- Single-value selection
- Multi-value selection
- Searchable options
- Clearable selection
- Disabled Select state
- Disabled individual options
- Option groups
- Select All
- Filtered Select All
- Required state
- Validation errors
- Controlled usage
- Placeholder
- Selected value display
- Multi-select chips
- Keyboard-friendly option interaction
- Full-width field layout
- Integration with `FieldWrapper`

## Basic Usage

The simplest way to use `Select` is to provide a list of options.

```tsx
const options = [
  {
    value: "react",
    label: "React",
  },
  {
    value: "typescript",
    label: "TypeScript",
  },
  {
    value: "javascript",
    label: "JavaScript",
  },
];

<Select
  label="Framework"
  options={options}
  placeholder="Select a framework..."
/>
```

[Open Basic Usage in Playground](/playground/select?focusId=select-basic-usage)

---

## Select Options

Each Select option uses a `value` and a `label`.

```tsx
const options = [
  {
    value: "react",
    label: "React",
  },
  {
    value: "vue",
    label: "Vue",
  },
  {
    value: "angular",
    label: "Angular",
  },
];
```

The `value` is used internally as the selected value, while `label` is displayed to the user.

---

## Searchable Select

The `searchable` property enables searching through available options.

```tsx
<Select
  label="Search Framework"
  searchable
  options={options}
  placeholder="Search frameworks..."
/>
```

When enabled, the Select menu provides a search field that allows the user to filter available options.

This is especially useful when the option list contains many items.

[Open Searchable Select in Playground](/playground/select?focusId=select-searchable)

---

## Clearable Select

The `clearable` property allows the current selection to be removed.

```tsx
<Select
  label="Framework"
  searchable
  clearable
  options={options}
  placeholder="Select a framework..."
/>
```

For a single Select, clearing the value resets it to an empty string.

For a multi Select, clearing removes all selected values.

---

## Multi Select

The `multi` property enables multiple option selection.

```tsx
<Select
  label="Technologies"
  multi
  options={options}
  placeholder="Select technologies..."
/>
```

When multiple values are selected, they are displayed as chips inside the Select field.

The value of a multi Select is an array of strings.

```tsx
const [value, setValue] = useState<string[]>([]);

<Select
  label="Technologies"
  multi
  value={value}
  onChange={setValue}
  options={options}
/>
```

[Open Multi Select in Playground](/playground/select?focusId=select-multi)

---

## Multi Select with Search

`multi`, `searchable`, and `clearable` can be combined.

```tsx
<Select
  label="Technologies"
  multi
  searchable
  clearable
  options={options}
  placeholder="Select technologies..."
/>
```

This configuration allows users to:

1. Search for options.
2. Select multiple options.
3. Remove individual selections.
4. Clear all selections.

## Disabled Select

Use `disabled` when the entire Select field should not be interactive.

```tsx
<Select
  label="Framework"
  disabled
  value="react"
  options={options}
/>
```

A disabled Select cannot be opened or changed by the user.

[Open Disabled State in Playground](/playground/select?focusId=select-states&innerFocusId=select-states-disabled)

---

## Disabled Options

Individual options can also be disabled.

```tsx
const options = [
  {
    value: "available",
    label: "Available Option",
  },
  {
    value: "disabled",
    label: "Disabled Option",
    disabled: true,
  },
];
```

A disabled option remains visible but cannot be selected.

This allows an option list to contain unavailable choices while keeping the Select itself interactive.

[Open Disabled Options in Playground](/playground/select?focusId=select-disabled-options)

## Option Groups

Options can be organized into labeled groups.

```tsx
const groupedOptions = [
  {
    label: "Frontend",
    options: [
      {
        value: "react",
        label: "React",
      },
      {
        value: "vue",
        label: "Vue",
      },
      {
        value: "angular",
        label: "Angular",
      },
    ],
  },
  {
    label: "Backend",
    options: [
      {
        value: "node",
        label: "Node.js",
      },
      {
        value: "dotnet",
        label: ".NET",
      },
      {
        value: "java",
        label: "Java",
      },
    ],
  },
];
```

The grouped options can then be passed directly to `Select`.

```tsx
<Select
  label="Technology"
  searchable
  options={groupedOptions}
  placeholder="Select a technology..."
/>
```

Groups can also be used with multi Select.

```tsx
<Select
  label="Technologies"
  multi
  searchable
  options={groupedOptions}
  placeholder="Select technologies..."
/>
```

[Open Option Groups in Playground](/playground/select?focusId=select-groups)

## Select All

Multi Select supports Select All behavior through the `selectAll` property.

```tsx
<Select
  label="Select Technologies"
  multi
  searchable
  clearable
  selectAll={{
    enabled: true,
    scope: "filtered",
  }}
  options={options}
  placeholder="Select technologies..."
/>
```

When enabled, the Select menu provides an option for selecting or clearing all available options.

---

## Filtered Select All

The `scope` property controls which options are affected by Select All.

```tsx
selectAll={{
  enabled: true,
  scope: "filtered",
}}
```

With `scope: "filtered"`, Select All operates on the options currently visible after filtering.

For example:

```text
All options
    ↓
User searches
    ↓
Filtered options
    ↓
Select All
    ↓
Only filtered options are selected
```

This behavior is especially useful when a Select contains a large number of options.

[Open Select All in Playground](/playground/select?focusId=select-select-all)

## Placeholder

Use `placeholder` to provide a hint when no value has been selected.

```tsx
<Select
  label="Framework"
  options={options}
  placeholder="Select a framework..."
/>
```

For multi Select:

```tsx
<Select
  label="Technologies"
  multi
  options={options}
  placeholder="Select technologies..."
/>
```

The placeholder is displayed only when there is no selected value.

## Required Field

The `required` property indicates that the field is required.

```tsx
<Select
  label="Framework"
  required
  options={options}
  placeholder="Select a framework..."
/>
```

The required state is primarily a visual and semantic field state.

Validation rules are handled by the FlowForge Form Engine.

## Validation Error

The `error` property displays a validation error associated with the field.

```tsx
<Select
  label="Framework"
  error="Please select a valid framework."
  options={options}
  placeholder="Select a framework..."
```

The Select component is responsible for displaying the error state.

The FlowForge Form Engine can provide validation results to the component.

## Controlled Select

`Select` supports the standard React controlled component pattern.

```tsx
import { useState } from "react";
import { Select } from "@/engine/components/form";

const options = [
  {
    value: "react",
    label: "React",
  },
  {
    value: "typescript",
    label: "TypeScript",
  },
  {
    value: "javascript",
    label: "JavaScript",
  },
];

export default function Example() {
  const [value, setValue] = useState("");

  return (
    <Select
      label="Framework"
      value={value}
      onChange={setValue}
      options={options}
      clearable
      placeholder="Select a framework..."
    />
  );
}
```

The current value is stored in React state and passed back to the Select through the `value` property.

[Open Controlled Select in Playground](/playground/select?focusId=select-controlled)

---

## Controlled Multi Select

The same controlled pattern can be used with multi Select.

```tsx
import { useState } from "react";
import { Select } from "@/engine/components/form";

export default function Example() {
  const [value, setValue] = useState<string[]>([]);

  return (
    <Select
      label="Technologies"
      multi
      value={value}
      onChange={setValue}
      options={options}
      placeholder="Select technologies..."
    />
  );
}
```

For multi Select, the controlled value is an array of selected option values.

---

## Single Select Value

A single Select uses a string value.

```tsx
const [value, setValue] = useState<string>("");

<Select
  value={value}
  onChange={setValue}
  options={options}
/>
```

The empty string represents no selected value.

---

## Multi Select Value

A multi Select uses an array of strings.

```tsx
const [value, setValue] = useState<string[]>([]);

<Select
  multi
  value={value}
  onChange={setValue}
  options={options}
/>
```

An empty array represents no selected values.

---

## Value Display

For single Select, the selected option label is displayed inside the field.

For example:

```tsx
<Select
  value="react"
  options={options}
/>
```

displays:

```text
React
```

For multi Select, selected values are displayed as chips.

```tsx
<Select
  multi
  value={["react", "typescript"]}
  options={options}
/>
```

The component manages the visual representation of the selected values while the underlying value remains an array.

---

## Keyboard Interaction

The Select component is designed to support keyboard-friendly option interaction.

Users can interact with the option list using standard keyboard interactions supported by the component.

Disabled options are not selectable through normal option interaction.

The exact keyboard behavior may evolve as the accessibility layer of FlowForge continues to develop.

---

## Full Width

Select fields use the available width of their parent form layout.

```tsx
<Select
  label="Framework"
  options={options}
  placeholder="Select a framework..."
/>
```

This allows Select to integrate consistently with other FlowForge field components such as `Input` and `Textarea`.

## API

### SelectProps

The exact `SelectProps` API should remain aligned with the implementation of the Select component.

The currently supported public configuration includes:

| Property | Type | Description |
| --- | --- | --- |
| `label` | `string` | Label displayed above the Select |
| `options` | `SelectOption[] \| SelectOptionGroup[]` | Available selection options |
| `value` | `string \| string[]` | Current selected value |
| `onChange` | `(value: string \| string[]) => void` | Called when the selection changes |
| `placeholder` | `string` | Text displayed when no value is selected |
| `multi` | `boolean` | Enables multiple selection |
| `searchable` | `boolean` | Enables option searching |
| `clearable` | `boolean` | Allows the current selection to be cleared |
| `disabled` | `boolean` | Disables the entire Select |
| `required` | `boolean` | Marks the field as required |
| `error` | `string` | Validation error message |
| `selectAll` | `SelectAllConfig` | Configures Select All behavior |
